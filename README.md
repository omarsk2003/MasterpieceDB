# MasterpieceDB
# LIFT Database

This preliminary SQL Server database.

## Setup

1. Open `LIFT_From_Scratch_Simple.sql` in SQL Server Management Studio.
2. Connect to a SQL Server instance that does not already contain a database named `LIFT`.
3. Execute the script once. It creates the database, tables, primary keys, foreign keys, and constraints.

## Current Scope

This is a preliminary database design. Payment processing, detailed AI usage limits, and access rules will be implemented in the application. The workflow for generating a plan and sending it to a specialist for review will be designed in a later phase.
